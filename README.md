# HousePricePredictor
A machine learning model that predicts prices of housing in California.

## Introduction

This house price predictor is trained on the fetch_california_housing dataset of scikit-learn, found in [this link](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html).

## Methods

A RandomForestRegressor was applied on the dataset.

## Results

The model obtains a R-squared of 0.8, a mean absolute error of 0.33 and root mean squared error of 0.51.
